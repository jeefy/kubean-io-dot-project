# Security Policy

## Reporting Security Issues

The Kubean maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kubean-io/kubean/security/advisories/new) form.

For more details, see the [Kubean security policy](https://github.com/kubean-io/kubean/blob/main/SECURITY.md).
